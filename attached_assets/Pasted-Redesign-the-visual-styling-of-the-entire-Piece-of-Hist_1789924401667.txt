Redesign the visual styling of the entire Piece of History application with a clean, premium icy/frosted glass aesthetic.

IMPORTANT:

- I have removed all previous frosting-related CSS.
- Build the frosting system from scratch.
- Do NOT recreate the previous complicated frost CSS.
- Keep the implementation lightweight, maintainable and performant.
- The application already uses Tailwind CSS. Prefer Tailwind utilities and existing Tailwind capabilities wherever possible.
- Only add small, reusable custom CSS when Tailwind cannot achieve the effect cleanly.
- Do not change application functionality, routing, API logic, authentication, components' behavior, or business logic.
- Do not introduce another UI framework.
- Preserve the existing responsive layout and fix/improve styling without breaking mobile.

1. Overall visual direction

Create a distinctive:

"Frozen Internet / Icy Glass / Snowy Blue"

visual identity.

The site should feel like a website that has been gently frozen in ice.

Use:

- snowy blue
- icy blue
- very light blue-white
- translucent white
- subtle cyan-blue highlights
- soft cold shadows

Avoid:

- strong saturated blue
- neon blue
- excessive gradients
- excessive glow
- excessive blur
- dark glassmorphism everywhere
- flashy animations

The result should look premium, minimal, playful and slightly mysterious.

2. Frosted glass system

Create a reusable visual system for:

Frosted cards

Use Tailwind classes wherever possible:

- translucent background
- "backdrop-blur"
- subtle border
- soft shadow
- slight inner highlight
- rounded corners

Example visual direction:

bg-white/50
backdrop-blur-md
border border-white/60
shadow-sm / shadow-md

Adapt the opacity depending on the background so text remains readable.

Cards should look like thin sheets of frosted ice, not plastic glass.

3. Frost effect

Create a subtle frost texture around important UI elements.

Use very restrained effects such as:

- subtle white transparency
- soft radial gradients
- extremely subtle blur
- low-opacity icy highlights
- tiny snow/frost details

Do NOT create large complicated pseudo-element systems.

If pseudo-elements are needed, keep them limited to reusable components/classes.

The frost should be visible when looking at the UI, but users should still immediately understand the content.

4. Buttons

Give primary buttons a subtle frozen-glass appearance.

They should have:

- icy blue background
- translucent highlight
- soft border
- subtle shadow
- slightly brighter hover state
- very small upward movement on hover

Example direction:

normal:
"bg-sky-500/90"

hover:
slightly brighter / stronger frost

active:
slightly compressed

Do not create huge glowing buttons.

Secondary buttons should use:

"bg-white/40 backdrop-blur"

with a subtle icy border.

5. Icons

Apply the frost aesthetic to icons without making every icon heavily decorated.

Icons should use:

- icy blue / slate-blue colors
- subtle translucent circular or rounded background where appropriate
- small frosted border for important icons
- gentle hover transition

Do NOT put large snowflake backgrounds behind every icon.

Only major decorative icons can have stronger frost treatment.

6. Hero section

The hero section should be the strongest expression of the frost theme.

Create a subtle frozen atmosphere using:

- icy blue background
- very soft radial gradients
- translucent frost/glass layers
- extremely subtle snow particles or floating frost details if already supported by the application

Do not create a heavy animated background.

The hero should remain readable and performant on mobile.

The main heading should feel like it is sitting inside a cold/frozen environment.

7. Competition / bidding cards

These are important parts of the application.

Make each competition card feel like a small piece of frozen history.

Use:

- frosted glass
- translucent white/icy background
- subtle icy border
- soft shadow
- slight hover elevation
- subtle blue highlight

On hover:

- card moves up by approximately 1–2px
- border becomes slightly brighter
- shadow becomes slightly stronger

Keep the transition around 150–250ms.

No excessive animation.

8. Winner / Piece of History area

The current winner should visually stand out.

Use a slightly stronger frost treatment:

- brighter glass
- subtle icy blue highlight
- slightly stronger border
- soft glow/shadow
- small snow/frost decorative element

The winner should feel special without looking like a neon gaming UI.

9. Background

Create a very subtle icy background.

Use Tailwind gradients where possible.

Suggested direction:

- very light snowy blue base
- subtle radial icy-blue highlights
- slight variation between sections

Do not use a giant gradient covering the entire page.

The background should provide enough contrast for frosted cards.

10. Typography

Preserve the application's existing typography.

If the project already uses:

- DM Sans
- Instrument Serif
- Space Mono

keep them.

Use typography intentionally:

DM Sans:

- body
- buttons
- UI

Instrument Serif:

- important editorial/curious headings

Space Mono:

- dates
- countdowns
- technical/small metadata

Do not replace the existing fonts.

11. Frosted navigation/header

Make the navbar feel like a thin frozen glass layer.

Use:

- translucent background
- "backdrop-blur"
- subtle bottom border
- slight shadow
- icy highlight

Example direction:

"bg-white/40 backdrop-blur-lg border-b border-white/50"

Make sure the navbar remains readable while scrolling.

12. Inputs

Inputs should also fit the frost system.

Use:

- translucent white background
- backdrop blur
- subtle icy border
- clear focus ring
- soft blue focus state

Avoid overly bright input backgrounds.

13. Small decorative frost details

Use snow/frost details selectively.

Possible elements:

- tiny snowflake symbols
- small icy dots
- subtle frost corners
- tiny translucent circles
- small floating particles

Do not decorate every component.

The design should have visual breathing room.

14. Animation philosophy

Animations should be subtle.

Allowed:

- opacity transitions
- small translate movement
- soft hover elevation
- very slow floating effect for decorative elements
- subtle snow particle movement

Avoid:

- flashing
- rapid movement
- strong pulsing
- excessive parallax
- constant expensive animations
- large blur animations

Respect "prefers-reduced-motion".

When reduced motion is enabled, disable decorative animations.

15. Mobile-first requirement

This is extremely important.

The frost system MUST NOT disturb the existing mobile layout.

Check:

- horizontal overflow
- card widths
- navbar
- buttons
- text wrapping
- hero spacing
- competition cards
- footer
- decorative elements

Decorative frost elements must never cause horizontal scrolling.

Use responsive Tailwind classes instead of fixed pixel positioning wherever possible.

16. Performance requirements

Keep the CSS lightweight.

Prefer:

Tailwind utilities
→ reusable component classes
→ minimal custom CSS

Avoid creating dozens of custom classes.

Avoid large SVG filters.

Avoid expensive "filter: blur()" animations.

Avoid huge box-shadow stacks.

Avoid unnecessary pseudo-elements.

Do not add a large CSS framework or dependency.

17. Reusable frost utilities

Create a small reusable visual vocabulary.

For example, if appropriate for the existing architecture:

- "frost-card"
- "frost-panel"
- "frost-button"
- "frost-nav"
- "frost-icon"
- "frost-highlight"

But only create these if they genuinely reduce repetition.

Prefer Tailwind composition when possible.

18. Existing application compatibility

Before making changes:

1. Inspect the current Tailwind configuration.
2. Inspect the current "index.css".
3. Inspect the existing component structure.
4. Identify the current color palette.
5. Identify existing utility classes.
6. Do not remove working styles unnecessarily.
7. Do not modify functionality.

Then implement the new frost design consistently across the application.

19. Most important design rule

The final result should NOT look like:

"website + random glassmorphism"

It should look like:

"Piece of History has been frozen in time."

Think:

❄️ snow
🧊 thin ice
🌨️ cold atmosphere
🥶 frozen internet
✨ subtle glass
📜 history/archive
🕰️ time freezing

The design should feel unique and recognizable while remaining clean and professional.

20. Final verification

After implementation:

- Test desktop
- Test tablet
- Test mobile
- Check for horizontal overflow
- Check text readability
- Check button contrast
- Check navbar while scrolling
- Check cards
- Check winner section
- Check footer
- Check dark mode if the application already supports it
- Ensure no previous frosting CSS needs to be restored
- Remove unused frost-related CSS created during the implementation
- Keep the final CSS concise

Do NOT over-engineer this.

The priority order is:

1. Beautiful visual hierarchy
2. Strong icy/frost identity
3. Excellent readability
4. Mobile stability
5. Performance
6. Maintainable CSS
7. Subtle animation

Make the result feel like a polished, intentionally designed indie web experience rather than a generic SaaS dashboard.
